# PR #59 — исправление блокеров ревью

2026-10-07.

- Согласованы конфликты с последовательным обходом броней #48 и защитой записывающего proxy #52, сохранены обе группы тестов.
- Запрос оценки больше не фиксируется как отправленный при отказе Telegram: следующий цикл повторяет отправку. Вызовы prompt сериализованы в одном процессе.

- Добавлены регрессии: отказ Telegram, затем успех; 50 ожидающих броней и подтверждённая 51-я.
- Миграции billing/review проверены на изолированном PostgreSQL 16; production база не затрагивалась.
