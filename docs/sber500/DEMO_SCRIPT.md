## SQL для 3:45, если табло не выложено

Показывать только агрегаты, запрос набрать заранее и запустить в кадре:

```sql
SELECT (SELECT count(DISTINCT telegram_user_id) FROM telegram_messages)  AS guests,
       (SELECT count(*) FROM table_reservation_orders)                  AS requests,
       (SELECT count(*) FROM model_interaction_audit
         WHERE created_at > now() - interval '7 days')                  AS model_calls_7d;
```
