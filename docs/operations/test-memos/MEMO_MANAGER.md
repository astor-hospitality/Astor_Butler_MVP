# Памятка менеджера смены — Дарья Анатольевна. Тест ланча 15.10

Вы ведёте смену как обычно и держите «стоп-кран». Все команды пишутся **в рабочей Telegram-группе** (бот — администратор);
из личного чата с ботом они не работают. Регистр не важен, можно с именем бота (`/stop@…`).

## 1. Стоп и возврат бота

| Команда | Что делает | Ответ бота |
| --- | --- | --- |
| **`/stop`** (`/стоп`) | пауза гостевой автоматики + **сводка открытых статусов**: заявки (ждут хостес / подтверждены), ланчи сегодня с составом, счета, поручения; без телефонов | «⏸ Butler остановлен. Остановил(а): …» + сводка |
| **`/start_butler`** (`/go`) | снимает паузу | «▶️ Butler снова работает…» |
| **`/status_butler`** | работает или стоит + та же сводка; ничего не меняет | «▶️ Butler работает…» / «⏸ Butler остановлен …» |

На паузе гость с бронью, изменением, ланчем или счётом получает «Сейчас заявки принимает команда вручную — передаю ваше сообщение,
с вами свяжутся», а его текст приходит в группу карточкой **«✋ Butler на паузе — сообщение гостя»** — дальше ведёте его руками.
Меню, ответы на вопросы, согласие и «позвать менеджера» работают; кнопки на уже присланных карточках — тоже. Повтор команды ничего не ломает.
Пауза переживает перезапуск — вернуть бота только `/start_butler`. **Когда жать `/stop`:** бот шлёт гостям не то, дублирует карточки,
гость жалуется, или вы решили вести смену руками. Сначала `/stop`, потом сообщение Диме и Михаилу.

## 2. Команды на смену (до 12:00)

| Команда | Зачем | Ответ бота |
| --- | --- | --- |
| **`/официант <стол> Даниил`** | официант стола статистов на **сегодня** (действует один день); `/официант 1-6 Даниил` — диапазон, `/официант 5 -` — снять, `/официант` — список | «Стол 5 на 15.10 — Даниил (daniil).» |
| **`/чаевые daniil <https://…> [заметка]`** | ссылка Даниила для чаевых (СБП на физлицо); по программе вносит Михаил, доступна и вам. Бот ссылку **не повторяет** — своё сообщение после ответа удалите; `/чаевые` — у кого ссылка есть / нет | «Ссылка для чаевых: Даниил (daniil) — сохранена. … Гость увидит её после «да» на чаевых за столом этого официанта.» |
| **`/ссылка host`** | ссылка и QR для **стойки хоста** (печать — Дима до четверга); `/ссылка daniil 5` — личная ссылка сотрудника: в карточке хостес будет «Привёл(а): Даниил» (отметка в журнале, не бонус) | фото QR + «🔗 Ссылка для гостя — …» |

Чаевые уходят **лично официанту**, только если есть все три: бронь гостя на сегодня со столом, назначение `/официант` на этот стол
и ссылка `/чаевые`. Иначе получатель — «Команда AERIS», как раньше.

## 3. Сегодня выключено

- **`/manual on|off`** — ручной режим «перегружены» для таймера автоподтверждения. Таймер выключен: бот ответит с пометкой
  «⚠️ Автоподтверждение сейчас выключено в настройках … режим сохранён и вступит в силу после включения». Нужен, только если Михаил
  включит таймер на прогон 2 — тогда заявка без ответа через 7 минут уходит карточкой «⏱ 7 минут без ответа …» в чат менеджера
  (сейчас это личный чат Михаила с ботом — уточнить).
- **`/табло`** — табло оценок выключено, бот промолчит. Истечение удержания стола тоже выключено: заявка без ответа держит стол до «Да» / «Нет» хостес.

## 4. Кто что решает

«Да» / «Нет», правка, «Гость сел», «Счёт» на карточке — хостес Дарья (вы дублируете, если её нет у телефона: «Да»/«Нет» работают
и у вас). Заказ в Presto, счёт на стол, «без лука» с кухней — Даниил. Закрыть заказ в Presto, терминал — Владислав.
`/stop`, назначения, слово «стоп» всему тесту — вы. Флаги на сервере, второй прогон (автомат с Saby), перезапуск бота — Михаил
и Дима: вы им пишете, сами ничего не трогаете.

Гостям слово «тест» не произносим; ничего не обещаем от имени бота (время, замены, порции, скидки). Если бот сломался — гость
обслуживается как обычный, без объяснений про бота. Карточки с телефонами из группы наружу не пересылаем.
