# Astor Glasses: чек-лист физической проверки перед показом

Дата: 2026-10-08. Сборка — с текущего `main` после мержа этого PR. Проверяет Михаил на своём iPhone и очках; из облака собрать и установить нельзя. Каждый пункт — «да/нет» и одна строка, что увидел. «Вроде работает» не считается.

Перед началом: в Xcode `xcodegen generate && pod install`, сборка на подключённый iPhone (Personal Team, ad hoc). Во вкладке «Очки»: адрес Astor, токен сотрудника (новый, прежний истёк 04.10), имя для приветствия — `Яна`.

Непрерывное видео с очков; слово «Астор» для запуска без касания; импорт записей из памяти очков по Wi‑Fi; TestFlight.

Результаты — комментарием в PR с номером пункта. Любое «нет» — отдельной строкой с тем, что было на экране и в журнале «Активность».
