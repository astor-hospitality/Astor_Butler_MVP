# C3 – сайт студии (c3ag.ru)

Сайт студии под новую айдентику: красное, тёмное, светлое и хром. Главный принцип вёрстки: картинка впереди, шрифт сзади. У типографики два полюса: огромное слово на экран и мелкие прописные подписи, середины почти нет.

Сайт только на русском. Латиницей пишутся знак C3, адреса и имена собственные (Clio, Instagram, Telegram, клиенты, имена основателей).

Next.js 16 (App Router, `output: "standalone"`) + TypeScript, Tailwind 4, GSAP + ScrollTrigger, Lenis. Страницы статические; серверный адрес `/api/watch` отдаёт фильм для плеера, `/api/chat` – локальная заглушка чата для разработки.

Фото, видео и шрифты в Git не лежат: они в S3, сайт берёт их по `NEXT_PUBLIC_MEDIA_BASE_URL`. Как развернуть сайт на c3ag.ru, какие настройки и какие файлы положить в S3 – в [DEPLOY_C3_SITE.md](DEPLOY_C3_SITE.md).

## Запуск

Нужен Node.js 20.9+ (в образе 22).

```bash
npm ci
# медиа (110 файлов, их передают отдельно) – в public/media: images/, videos/, fonts/
npm run dev
```

Откроется на http://localhost:3001 (порт 3000 занят Grafana из docker-compose бэкенда). Пока `NEXT_PUBLIC_MEDIA_BASE_URL` пустая, медиа отдаёт сам Next из `public/media` (папка в `.gitignore`).

Проверки и сборка:

```bash
npm run typecheck
npm run lint
npm run media:check   # совпадает ли content/media-manifest.ts с public/media
NEXT_PUBLIC_MEDIA_BASE_URL=https://<s3>/<bucket>/<prefix> npm run build
```

Старые адреса c3ag.ru (`/ru`, `/en`, `/ru/<направление>`, `/studio`, `/smart-solutions`, `/films` и др.) перенаправляются на новые страницы (`next.config.ts`).

## Медиа

Каждая картинка, ролик и шрифт называется путём от корня медиа (`images/refs/hero.png`, `videos/hero.mp4`, `fonts/…`), адрес строит `src/lib/media.ts`. Размеры картинок для next/image и короткий хеш каждого файла лежат в `content/media-manifest.ts` (он в Git); его делает `npm run media:manifest` из `public/media`. Хеш идёт в адрес как `?v=…`, поэтому заменённый файл получает новый адрес и кэш его не держит.

Добавить или заменить файл: положить в `public/media`, `npm run media:manifest`, закоммитить манифест, залить файл в S3 (`npm run media:upload-plan` печатает команды), пересобрать.

## Как устроена главная

Главная красная по краям и светлая посередине; чёрный на ней стоит в одном месте, под текстом «О нас» (так решил Рома, 2026-10-11). Цвет страницы меняется плавно, когда следующий экран доходит до середины окна, поэтому жёстких стыков нет.

1. **Первый экран (тёмный)**: шоурил один на весь экран, сразу после заставки с вращающимся знаком. Букв «C3» поверх него больше нет (слово Ромы, 2026-10-16: «чистый видеоряд»). Сверху подпись «Студия C3 / видеопродакшн», внизу «Листайте вниз» и «Шоурил». Экран высотой в одно окно, фильм чуть отстаёт от страницы и уезжает прямо в чёрный экран «О нас» (`MaskHero.tsx`).
2. **О нас (чёрный)**: экран чуть ниже окна (84svh), а над «Услугами и ценами» меньше воздуха, чем над другими экранами: иначе пауза между текстом и услугами выходила слишком длинной. Две короткие фразы крупными прописными, только белым: «C3 – независимая продакшн-студия. Мы ловим энергию до того, как она исчезает.» Они печатаются сами, по буквам за тонким курсором, когда экран появляется в окне (как фраза на заставке bbx.media). От прокрутки ничего не зависит (`About.tsx`, фразы в `content/site.ts`).
3. **Услуги и цены (светлый)**: заголовок «Услуги и цены» одной красной строкой от поля до поля, вплотную над первым направлением (небольшой заголовок выглядел здесь чужим). За ним семь направлений подряд, по экрану на каждое, все на светлом, между ними тонкая линия. Экран направления разгружен (слово Ромы, 2026-10-11): номер, название огромным словом, картинка поверх нижней части названия, одна тихая строка обычным текстом и цена, подчёркнутая красной линией (без стрелки: так нарисовал Рома), она же ссылка на страницу направления. Цена набрана жирными прописными в размере заголовка: на широком экране она стоит внизу слева, на уровне нижнего края картинки, чтобы левая половина не выглядела пустой; на телефоне так же жирно, сразу под строкой (слово Ромы, 2026-10-16). «Для кого» и всё остальное живёт на странице направления. Подсказки Clio про направления в этом ряду не всплывают, они показываются на страницах направлений. Обложки направлений – новые картинки студии (см. ниже).
   Картинки направлений – фирменные работы студии (Сергей, 2026-10-14), места выбрал Рома (2026-10-16): хромированный дроид у ИИ-роликов («c3 pio», «точно для AI раздела»), попугай у репортажа, бургер со знаком у вертикальных роликов (они для ресторанов и баров; «вкусный и сочный контент»), очки у рекламы, овца из попкорна у кино (чтобы смотреть кино, надо что-то жевать). У подкастов и свадеб стоят кадры из работ. Все фирменные картинки живые: поверх кадра идёт короткий ролик туда и обратно. У направления может быть отдельная картинка для его страницы (`pageCover`), сейчас не используется. На широком экране строка под названием набрана заголовочным размером, на телефоне она текстовая.
4. **Леденец (светлый)**: фраза «Научись снимать или отойди и подержи это.» огромными словами, леденец стоит перед ними справа, рядом со словом «это» (`PosterPause.tsx`).
5. **Работы (светлый)**: слово «РАБОТЫ», фильтры по направлениям, лента вертикальных карточек, которая уходит за правый край.
6. **Собрать съёмку (светлый)**: конфигуратор «Соберите съёмку за три шага» в тонкой красной рамке.
7. **О студии (светлый)**: слово «СТУДИЯ» за хромированным геймпадом, текст студии, четыре места команды.
8. **Факапы на съёмках (светлый)**: плакат студии с упавшим мороженым, лужица которого – знак (живой ролик), под ним две строки мелкими прописными по краям картинки, как на самом плакате: «Факапы на съёмках» и «Ни один дубль не застрахован» (`Fails.tsx`). Сергей хотел «рассказать про факапы на съёмках»: сами истории пишет студия, они встанут под плакатом пронумерованными (`fails.stories` в `content/site.ts`); пока их нет, блок – один плакат.
9. **Финал (красный)**: «ИГРАЕМ?» чисто белым в белой рамке, кнопка «Обсудить проект», контакты столбиком, подвал.

Чего на главной нет по решению Ромы (2026-10-11): списка направлений под первым экраном (его повторяют экраны направлений), блока «Как мы работаем», блока с объяснением, что такое Clio, отдельного экрана с попугаем, строки «Производство без лишних слов.» над направлениями.

Полная загрузка начинается с красного экрана со знаком и счётчиком 0–100, он держится полторы секунды. Знак на нём – фирменный хромированный знак студии; там, где браузер умеет показывать прозрачность видео WebM (Chrome, Edge, Firefox), поверх встаёт анимация студии, где знак поворачивается (`videos/logo-spin.webm` в медиа). В Safari и на iPhone остаётся неподвижный знак со вспышкой. Время считается с момента, когда экран реально нарисован в открытой вкладке.

Шапка маленькая и закреплена: знак, «Услуги / Работы / О студии», справа «Обсудить проект». При прокрутке вниз прячется, вверх возвращается. На телефоне в ней только знак и «Обсудить проект».

В углу на всех экранах стоит звезда Clio.

При «уменьшении движения» в системе ничего не закрепляется и не едет: вместо фильма стоит кадр, слова и картинки просто на месте.

## Цвета и шрифты

Цветов четыре, других в проекте нет (`src/app/globals.css`):

- `--color-ink` `#0A0A0A` – тёмные экраны, у них по краям красная виньетка и немного зерна. На главной это только «О нас»; на страницах направлений тёмные первый экран и «Стоимость»;
- `--color-paper` `#EFF0F2` – светлые экраны;
- `--color-red` `#B80314` – акценты, номера, плашки, красные экраны;
- `--color-white` `#FFFFFF` – текст на красном.

Градиенты разрешены только для бликов на хроме и карточках и для виньетки.

Шрифт один – TT Travels Next: заголовки, огромные слова, мелкая прописная и обычный текст (слово Ромы, 2026-10-16; Muller Next убран).

Размеров шрифта три, других нет (слово Ромы, 2026-10-11, подтверждено 2026-10-16; до этого их было около двадцати). Они записаны в `:root` в `globals.css`:

- `--fs-s` – мелкие прописные, 12 px: подписи, навигация, номера, кнопки, чипы;
- `--fs-t` – текст, 16–18 px: всё, что читают, и короткие жирные названия внутри рамок, в том числе названия работ в карточках ленты (все одного размера);
- `--fs-m` – заголовок, от 22 px на телефоне до 52 px на широком экране: названия блоков («Услуги и цены», «Стоимость», «Соберите съёмку за три шага»), цена на экране направления, цены в карточках пакетов.

Новый текст берёт один из трёх. Всё, что крупнее, – огромные слова и фразы: «C3», названия направлений, фразы «О нас», фраза с леденцом, «РАБОТЫ», «СТУДИЯ», «ИГРАЕМ?». У них нет своего размера, они подгоняются под ширину экрана. Карточки пакетов стоят не больше чем по две в ряд: цена набрана заголовком и должна помещаться в одну строку.

Огромные слова считаются от ширины экрана и ширины самого слова, поэтому доходят от поля до поля и на телефоне не обрезаются. Размеры букв шрифта записаны в `src/lib/travels.ts` (сняты с файла шрифта). Если заменить файл шрифта, эту таблицу нужно снять заново.

## Лента работ и плеер

Лента (`src/components/sections/WorksRail.tsx`) тянется мышью, листается свайпом и с клавиатуры, останавливается на карточках. Стрелок у фильтров нет (слово Ромы, 2026-10-16). Фильтры – рамки с текстом; на широком экране все восемь стоят в один ряд от окна 1140 px, уже переносятся на вторую строку, на телефоне ряд листается. Под ней тонкая красная линия показывает, где вы в ленте. Фильтр пишется в адрес (`?dir=ai`). У свадеб работ пока нет, вместо ленты стоит красная плашка с кнопкой. Последняя карточка красная: «Архив, ещё N работ», она открывает чат Clio.

Под курсором карточка играет короткий немой ролик, по ней пробегает блик. На телефоне играет та карточка, которая целиком на экране. Клик открывает плеер на весь экран (`VideoLightbox.tsx`): фильм со звуком, стрелки к соседним работам, Esc или свайп вниз закрывают.

Откуда берётся видео:

- короткие ролики для карточек лежат в медиа, в `videos/work`. Их режет `tools/film/work_clips.py` (инструменты сайта живут в рабочей папке сайта, не в этом репозитории) прямо с Яндекс Диска студии, по 6 секунд без звука. Сейчас нарезано 10 из 32: Диск начал отказывать. Скрипт можно запустить снова, готовые он пропустит;
- после нарезки нужно запустить `tools/film/work_media.py`: он обновляет `content/work-media.ts`;
- полный фильм плеер просит у `/api/watch`. Этот адрес берёт у Яндекса свежую ссылку на исходник и отправляет браузер по ней, без заголовка Referer: с чужого сайта Яндекс фильм не отдаёт. Исходники разные: H.264 играет везде, 4K в HEVC только там, где его умеет устройство. Если фильм не заиграл или Диск не ответил, плеер показывает короткий ролик или кадр.

Плюс на карточке кладёт работу в «раскадровку» – список референсов посетителя (`src/lib/board.ts`). Он живёт, пока открыта вкладка, из него берёт работы конфигуратор.

## Конфигуратор съёмки

«Соберите съёмку за три шага» (`src/components/sections/Shoot.tsx`) – одна тонкая красная рамка на тёмном, три колонки: что снимаем, пакет, референсы. По нижнему краю итог и кнопка «Отправить Clio». После отправки раскадровка уходит в чат Clio одним сообщением.

Всё, что конфигуратор говорит и предлагает, лежит в `content/shoot.ts`. Пакеты и цены читаются из `content/products.ts`, то есть из тех же данных, что на странице направления.

Когда что-то выбрано, за посетителем ходит плашка «Раскадровка · 70 000 ₽ · 2 кадра» (`src/components/ShootChip.tsx`).

## Где что лежит

- `content/site.ts` – все тексты главной, семь направлений с ценами, команда, контакты, слова Clio.
- `content/products.ts` – страницы направлений: пакеты, цены, состав, шаги, сроки и условия.
- `content/catalog.ts` – работы по направлениям; `content/work-media.ts` – их видео (делается скриптом).
- `content/cases.ts` – работы со своей страницей.
- `content/media.ts` – картинки и фильм первого экрана. Фирменные картинки в `images/refs`, кадры работ в `images/work`, видео в `videos` (всё в медиа, см. выше). Ролики и кадры фирменных работ делает `tools/film/brand_media.py` из файлов студии (обрезка 4:5, 720 × 900, туда и обратно, без звука; анимация знака – WebM с прозрачностью).
- `content/hints.ts` – подсказки Clio: тексты и правила показа.
- `src/app/globals.css` – палитра, шрифты, сетка, стили всех экранов.
- `src/components/sections` – экраны главной: `MaskHero`, `About`, `Directions`, `PosterPause`, `Works`, `Shoot`, `Studio`, `Final`, `Footer`.
- `src/components` – общие части: `Screen`, `MaskWord` (слово-маска), `Lines` (строки, которые открываются по очереди), `StarFlare`, `Reveal`, `RevealImage`.
- `src/components/motion` – заставка, курсор, плавный скролл, смена цвета страницы.
- `src/components/assistant` – Clio: звезда, подсказки, окно чата. Связь с сервером в `src/lib/clio.ts`.
- `src/lib/media.ts`, `content/media-manifest.ts`, `scripts/media-manifest.mjs`, `scripts/media-upload-plan.mjs` – медиа из S3 (см. «Медиа»).
- `src/app/api/watch` – фильм для плеера; `src/app/api/chat` и `src/lib/clio-persona.ts` – демо-ответы Clio для локальной работы (`NEXT_PUBLIC_WEB_CHAT_ENDPOINT=/api/chat`).
- `public/docs/policy.html` – политика обработки персональных данных C3AG (на неё ссылаются чат, подвал и `ConsentController` бэкенда).
- `tools/chrome`, `tools/film`, `tools/concept` (рендер знака, нарезка видео, макеты) в этот репозиторий не входят.

## Что ещё лежит в frontend/

- `astor-butler/` – статический сайт Astor (`c3ag.ru/astor/`), к Next-приложению не относится: его отдаёт `astor-site` прямо из этой папки, тесты гоняет CI (`node --test frontend/astor-butler/tests/*.test.mjs`).
- `data/videos.json`, `scripts/object-storage-publish.mjs`, `scripts/yadisk-enable.mjs` – опись архива студии и выкладка роликов в бакет `c3ag-media` от прошлой версии сайта; новый сайт их не читает.
- `C3_PRODUCTS_HANDOFF.md`, `CODEX_HANDOFF_REPORT.md`, `FRONTEND_PRODUCTION_PLAN.md`, `NEXT_SESSION_PLAN.md` – заметки о прошлой версии сайта (до 2026-10-16), оставлены как история.
