Коммерческое предложение

Коротко

Astor Butler — цифровой дворецкий для ресторана: Telegram-first сервис, который принимает запросы гостей, ведет их по понятным сценариям и передает команде только подтвержденные действия.

Зачем продукт

Ресторану нужен не еще один бот. Ресторану нужен слой управления гостевым вниманием.

Astor Butler снижает потери в моментах:

  • гость хочет бронь, но не дозвонился;
  • хостес не видит историю сообщений;
  • просьба «свечу к десерту» теряется;
  • предпочтение «без острого» забывается;
  • менеджер видит проблему слишком поздно;
  • простая заявка превращается в ручной хаос.

Покупатель и пользователь

Покупатель: ресторатор, отельер, управляющая компания, event-площадка.
Пользователь: гость, который пишет в Telegram или будущий web chat.
Операторы: хостес, staff, менеджер, администратор.

Что входит в первый пакет для ресторана

  • Telegram guest flow;
  • preview ресторана;
  • consent/contact flow;
  • сценарий бронирования стола;
  • сценарий меню / quiet guide;
  • сценарий service request;
  • уведомления manager/staff/admin/system;
  • Preference Map для явных предпочтений;
  • draft-confirmation flows для merch/tips/donation/auction;
  • базовая аналитика / event trail;
  • документация для гостя, стаффа и менеджера;
  • сопровождение и обновления MVP-контура.

Стоимость первого пилота

30 000 ₽ / месяц базовая подписка для AERIS / первого ресторана · 01.07.2026 — 30.06.2027

Отдельно перевыставляются: удаленная машина Selectel; домен/DNS при необходимости; хранение медиа; дополнительные интеграции; съемка/контент; нетиповая доработка.

Продажи

Этап 1

  • 10 ресторанов RU-сегмента;
  • 1 отель;
  • ручные демонстрации;
  • кейс AERIS;
  • интервью основателя;
  • презентация сценариев на одном съемочном дне.

Этап 2

Пакет для отелей, пакет для ресторанных групп, managed infrastructure, city/stadium hospitality layer. Этап 2 публично не раскрывается в первом КП.

Почему сейчас

Рынок устал от чат-ботов, которые отвечают «не туда». Astor Butler продает не бот, а управляемое внимание: сценарий, память, подтверждение, контекст для команды.

Призыв

Первое действие для ресторатора:

  1. выбрать 3 сценария, которые чаще всего теряются;
  2. подключить Telegram guest entry;
  3. проверить неделю живых запросов;
  4. решить, какие сценарии автоматизировать дальше.
